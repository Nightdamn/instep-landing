# InStep Landing

Публичная посадочная страница платформы InStep (`instep.expert`) для учеников и мастеров.
Отдельный проект от приложения (`Nightdamn/healthwalk`), тот же стек: React 18 + Vite, без TypeScript.

## Запуск

```bash
npm install
npm run dev        # http://localhost:5180
npm run build      # dist/
npm run preview    # http://localhost:5181
```

## Структура

```
src/
  App.jsx                 порядок секций страницы
  components/             Header (липкая шапка, мобильное меню), Footer (вход, кнопки приложений), Logo
  sections/
    Hero.jsx              первый экран: заголовок, кнопки, телефон с экраном дня, лента дня
    Day.jsx               «Один день курса»: липкая лента-прогресс и пять остановок
    Sections.jsx          разделы приложения для ученика и мастера
    Courses.jsx           реальный курс + курсы-примеры
    Reviews.jsx           отзывы (пока примеры формата)
    stops.js              остановки дня (ид, время суток, название, иконка)
  demo/                   живые мини-экраны приложения на тех же токенах:
                          Phone (кадр), DayScreen, TimerScreen, CallScreen, TaskScreen, CabinetScreen
  data/content.js         весь текст и данные страницы; реальное помечено источником, примеры isExample
  styles/global.css       токены, унаследованные от приложения, сброс, стекло, фокус, скроллбар
public/
  icons/*.svg             иконки практик из приложения; icons/logo.svg это логотип курса, не платформы
  tracker-icons/**        каталог иконок приложения
```

## Дизайн

  Токены и правила: `DESIGN.md`, машинная копия `.impeccable/design.json`.
- Продуктовая правда: `PRODUCT.md`. Контракт направления страницы: `.impeccable/surfaces/src-app-jsx.md`.
- Структура «Один день курса» выбрана Димой 2026-10-23 из раздачи impeccable (seed 5d22dda7, re-roll 1).

## Правда и примеры

- Реальный курс: «Осознанная Походка», данные из прод-БД на 2026-10-23 (17 дней, 27 практик, 19 участников).
  Обновлять руками в `src/data/content.js` или подключить `GET /api/store` приложения.
- Курсы «Дыхание на 21 день» и «Столб» и все отзывы помечены как примеры до появления настоящих.
- Мини-экраны приложения собраны в React на токенах приложения; при появлении реальных скриншотов
  или тестового аккаунта их можно заменить картинками.
- Кнопки Google Play / App Store / APK помечены «скоро» и никуда не ведут.

## Деплой

Адрес: `https://site.instep.expert` (решение Димы 2026-10-23), сервер instep-prod `77.222.42.201`,
каталог `/opt/instep-landing`, nginx-сайт `site.instep.expert` отдаёт `dist/`.
Репо публичный: `github.com/Nightdamn/instep-landing`, сервер тянет его без учётных данных.

```bash
# с ПК: push в main, затем
ssh -i C:/AI/keys/instep_server root@77.222.42.201 "bash /opt/instep-landing/deploy/deploy.sh"
```

Конфиг nginx лежит в `deploy/nginx/` (включая 443-блок, дописанный certbot). Сертификат Let's Encrypt
выпущен 2026-10-23, продлевается автоматически; HTTP редиректит на HTTPS. `deploy.sh` конфиг не трогает,
при изменении конфига копировать его в `/etc/nginx/sites-available/site.instep.expert` руками и `nginx -t`.
